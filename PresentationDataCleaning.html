What is Data Cleaning Good for?

Key benefits:

  • Accuracy of results by removing errors, duplicates or other inconsistencies

  • Consistency across datasets makes it possible to merge and compare datasets without conflict

  • Handling missing values to prevent biased outcomes

  • Better modeling and predictions when using statistival models

see Kabacoff (2024), Lee (2025)

Overview

Package Function Use
dplyr select select variables/columns
dplyr filter select observations/rows
dplyr mutate transform or recode variables
dplyr summarize summarize data
dplyr group_by identify subgroups for further processing

Learning my Doing

Task:What is the average female and male height (in m) and mass in the “starwars” data set?

# install.packages("tidyverse")
library(tidyverse)
view(starwars)

Try to use the functions: - select() - filter() - mutate() - drop_na() - group_by() - summarise()

Possible Solution

starwars %>%
  select(sex, height, mass) %>%
  filter(sex == "male" | sex == "female") %>%
  mutate(height = height/100) %>%
  drop_na() %>%
  group_by(sex) %>%
  summarise('Average height' = (mean(height)),
            'Average mass' = mean(mass))
# A tibble: 2 × 3
  sex    `Average height` `Average mass`
  <chr>             <dbl>          <dbl>
1 female             1.72           54.7
2 male               1.78           80.2
